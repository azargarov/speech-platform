# M05A prompt v1

Use this system instruction for one model invocation per included test case:

> Transform the supplied text exactly as requested. Mode `raw` means preserve
> the source wording and meaning, except for the requested translation.
> `written` makes spontaneous speech coherent written language. `polite` does
> that and uses courteous professional wording. `diplomatic` does that and
> uses tactful diplomatic wording while retaining the speaker's actual
> position. These are behavior levels, not sequential passes. Formatting is
> exactly one of `normal`, `concise`, or `structured`; `concise` shortens only
> wording that can be removed without losing material information, and
> `structured` organizes the same information without adding facts. `raw`
> supports only `normal` formatting. Translate to the requested target language
> in the same response when one is specified; otherwise retain the input
> language(s). Preserve every fact, event, number, date, name, technical
> identifier, negation, uncertainty, request, commitment, criticism, complaint
> and relevant emotional intent. Do not soften, strengthen, omit, resolve or
> reinterpret those details. Do not infer causes, outcomes, apologies,
> commitments or work in progress. If a phrase is ambiguous, preserve its
> ambiguity. Return only the transformed text, with no preface or explanation.

The user message is a compact JSON object containing `mode`, `formatting`,
`target_language` (language code or `null`) and `text`. The corpus is synthetic.
Prompt text and generation options are held constant across candidates.

## Generation settings

- API: Ollama `/api/generate`, non-chat, one request at a time.
- `stream: true`; `keep_alive: "10m"` during a candidate run, followed by an
  explicit empty generation request with `keep_alive: 0` to unload.
- `options`: `num_ctx=4096`, `num_predict=512`, `temperature=0`,
  `top_p=1`, `seed=20261022`, `num_batch=128`, `num_thread=8`.
- `think: false` to request direct output for models that expose a reasoning
  control. Record any unsupported setting or leaked reasoning separately.
- Request timeout: 300 seconds per case; no retries. A failed request is
  recorded and stops that candidate run.
- If the local Ollama version/model does not honor a setting or exposes
  reasoning by default, record this as a deviation. No separate reasoning
  comparison is planned unless direct-output compliance cannot be achieved.

The request settings are evaluation controls, not production configuration.
